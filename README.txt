# EasyCode - 你的vibe-coding搭子

## Git 仓库地址
https://github.com/Liquor12138/easycode.git

## 如何运行

### 后端启动
1. 安装依赖：
   ```
   cd backend
   pip install -r requirements.txt
   ```

2. 配置环境变量：
   ```
   # 复制示例配置文件
   cp .env.example .env
   # 在 .env 文件中填入您的 DeepSeek API 密钥
   ```

3. 启动后端服务：
   ```
   python main.py
   ```
   后端将在 http://localhost:8000 运行

### 前端启动
1. 安装依赖：
   ```
   cd frontend
   npm install
   ```

2. 启动前端开发服务器：
   ```
   npm run dev
   ```
   前端将在 http://localhost:5173 运行


## 特色功能说明

1. **多工具集成**：支持12种开发工具，涵盖文件操作、代码编辑、系统执行和计划管理等方面，帮助AI助手高效完成编程任务。

2. **计划驱动工作流**：AI助手会在执行任务前制定详细计划，并实时更新执行进度，使开发过程更加可控。

3. **文件修改确认**：高亮显示代码修改，询问用户确认后执行，确保代码变更符合预期。

4. **上下文压缩优化**：具备智能对话历史压缩机制，防止上下文无限膨胀导致性能下降。

5. **安全执行环境**：内置路径沙箱和危险命令拦截机制，确保代码执行安全。

6. **可视化工具调用**：前端界面为不同的工具调用使用不同颜色图标展示，命令执行结果以终端风格呈现，便于理解AI的操作。

7. **实时终端反馈**：集成xterm.js终端组件，可实时查看命令执行结果。

8. **性能可配置**：最大执行次数、对话压缩触发阈值、压缩条数等关键参数均可通过环境变量配置，适应不同场景需求。

9. **跨平台兼容**：支持Windows、macOS、Linux等多种操作系统，适应不同开发环境需求。


## 支持的工具及功能

### 文件操作工具
1. **read_file**：读取指定路径文件的内容，支持指定编码格式
2. **write_file**：将内容写入指定路径的文件，自动创建所需父目录
3. **list_directory**：列出指定目录的内容，支持递归列出子目录

### 代码编辑与搜索工具
4. **search_replace**：在文件中精确查找一段文本并替换为新文本，要求原文本在文件中唯一匹配
5. **search_text**：在文件或目录中搜索包含指定文本的行，支持正则表达式和文件名过滤
6. **get_diagnostics**：获取文件的编译器/linter报错信息，支持Python、JavaScript/TypeScript、Java等语言
7. **list_symbols**：列出源代码文件中定义的符号，包括函数、类、变量等，支持Python、JavaScript/TypeScript、Java、C/C++等多种语言

### 系统执行工具
8. **execute_command**：在工作目录中执行终端命令，支持系统命令和已安装的可执行程序
9. **get_workdir**：获取当前工作目录的绝对路径

### 计划管理工具
10. **create_plan**：制定分步完成计划，在执行任何实际操作前调用
11. **update_step**：将计划步骤标记为已完成，每完成一个步骤后调用
12. **finish_task**：所有计划步骤完成后调用，提交最终总结并结束任务
